#### Havuzlu ( Toplu Mining ) için Katılım

<img width="1493" height="956" alt="image" src="https://github.com/user-attachments/assets/a31aeda8-b4d1-4506-b749-e8727aaf3a56" />

- 1: Cüzdan adresin.
- 2: Sunucuna & minerına vereceğin isim.
- 3: Sunucuna & minerına en yakın lokasyondaki pool'u seç.
- 4: Alt kısımdan sunucu & pc için uygun işletim sistemi & dosyayı seç ben linux sunucuda yaptım.

#### Genel Sunucu Güncelleme: 

```bash
sudo apt install htop ca-certificates zlib1g-dev libncurses5-dev libgdbm-dev libnss3-dev tmux iptables curl nvme-cli git wget make jq libleveldb-dev build-essential pkg-config ncdu tar clang bsdmainutils lsb-release libssl-dev libreadline-dev libffi-dev jq gcc screen file unzip lz4 -y
```

- Screen Açalım Hiç Kapanmadan Devam Etsin:

```bash
screen -S prl
```

- Kendinizdeki Kopyaladığınız Komutu Sunucuda Girin & Artık Başlayacaktır - CTRL A+D Yapıp Screenden Çıkabilirsiniz Devam edecek;
